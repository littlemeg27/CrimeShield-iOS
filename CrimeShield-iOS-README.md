# CrimeShield iOS

iOS companion to CrimeShield. Built for Full Sail University Project and Portfolio IV: Computer Science.

Same product idea as the Android app: give people a simple place to check community safety information on their phone. Android version: [CrimeShield---Android](https://github.com/littlemeg27/CrimeShield---Android).

## Features

- Native iOS client
- Xcode project in the `CrimeShield` folder
- Design files (Adobe XD) and milestone plans included

## Tech stack

| Layer | Tools |
|---|---|
| Language | Swift |
| Platform | iOS |
| Design | Adobe XD |

## Project status

Course project complete (`Crime Shield iOS final` commit).

## Getting started

1. Clone the repo
2. Open the Xcode project in `CrimeShield/`
3. Select an iPhone simulator or device
4. Build and run

```bash
git clone https://github.com/littlemeg27/CrimeShield-iOS.git
```
